# Encrypted personal books

The website and book titles remain public. Only ciphertext PDF chunks are published. This is not server-side login: an attacker can download ciphertext and guess passwords offline. Use 5–6 random words (at least 16 characters); a PIN is not suitable. GitHub and same-origin JavaScript remain in the trust boundary; compromised delivered JavaScript can steal an entered passphrase. No security-audit certification is claimed.

Setup: run `node scripts/setup-book-password.mjs` from `prototype`. It binds a random loopback port, accepts a one-shot same-origin CSRF-protected request, and encrypts the 13 explicit NAS source files. The user types and confirms their own passphrase. No password is logged or saved. It produces `public/encrypted-books/catalog.json` only after all files finish. The process does not upload automatically; verify output before publishing. An existing output is never overwritten. A failed partial output must be inspected/moved aside before retrying. The setup listener expires after one hour.

Format v1: PBKDF2-HMAC-SHA256, 600,000 iterations, independent random 128-bit salt per book, AES-256-GCM with independent random 96-bit IV per 8 MiB chunk and 128-bit authentication tag. Authenticated additional data binds the format, random book ID and chunk position. A small authenticated check rejects a wrong key before large downloads. Every encrypted chunk is decrypted and compared with input during packing. Native Node/browser Web Crypto implements all cryptographic operations.

Browser: derives a non-extractable key in memory; no passphrase/key storage. Closing cancels downloads, revokes the Blob URL and drops references. Idle reading locks after five minutes. JavaScript cannot promise memory zeroization. Downloading an unlocked PDF intentionally creates a plaintext copy outside this protection. Reading notes/page positions are local and **unencrypted**, not cross-device synced; old SHA-keyed notes are reused when available. The old GitHub token reader remains in source for migration but is not the active library or automatically connected.

Large scanned PDFs must download and decrypt before opening; mobile memory/performance depends on the device. Range streaming/OCR/reflowed EPUB text are not claimed. Forgotten passphrases cannot be recovered; use retained originals to create a new collection. Previously published ciphertext cannot be recalled from others' copies or Git history.
